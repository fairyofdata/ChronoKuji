# ADR-004: PC 대개방형 2-컬럼 시네마틱 UI 및 🖼️ 감상 모드 (Zen Mode) 채택

- **상태 (Status)**: `Accepted`
- **결정 일자 (Date)**: 2026-09-01
- **의사결정자**: UI/UX 디자이너 & 프론트엔드 리드

---

## 1. 배경 및 문제 상황 (Context)
- 모바일 1열 카드 형태의 불투명 박스(`bg-gray-900`) 구조는 PC 와이드 모니터에서 심각하게 답답하고 폐쇄적인 느낌을 줌.
- 배경 이미지가 블러와 불투명 박스에 가려져, 정성껏 제작된 8K 고화질 아트워크의 시각적 가치가 사용자에게 전달되지 못함.

## 2. 의사결정 (Decision)
- **전체 화면 생생한 캔버스 (Vivid Canvas)**:
  - 과도했던 배경 블러를 걷어내고 브라우저 전체 화면에 선명한 세계관 원본 일러스트를 벽지처럼 렌더링 + 은은한 시네마틱 비네팅 적용.
- **초슬림 투명 플로팅 글래스 (`bg-black/40 backdrop-blur-2xl border border-white/10 rounded-3xl`)**:
  - UI 박스를 30% 투명도로 띄워 뒤편의 광활한 배경 풍경이 UI 사이사이로 투과되는 대개방형 오픈 스페이스 완성.
- **🖼️ 원클릭 전체화면 감상 모드 (Zen Mode)**:
  - 헤더에 `🖼️ 감상 모드` 버튼을 두어, 클릭 한 번으로 모든 UI를 숨기고 고화질 일러스트와 BGM만 감상할 수 있는 시네마틱 힐링 뷰 지원.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - PC 환경에서 "내가 진짜 그 세계관에 들어와 있다"는 압도적인 개방감과 시각적 만족감 제공.

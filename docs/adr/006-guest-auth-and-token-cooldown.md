# ADR-006: UUID 게스트 인증 및 20시간 토큰 쿨다운 리텐션 모델

- **상태 (Status)**: `Accepted`
- **결정 일자 (Date)**: 2026-08-31
- **의사결정자**: 백엔드 & 그로스 엔지니어

---

## 1. 배경 및 문제 상황 (Context)
- 복잡한 소셜 로그인이나 회원가입 절차는 캐주얼 점괘 웹 서비스의 초기 진입 장벽(이탈률)을 크게 높임.
- 반면 인증이 전혀 없으면 유저의 뽑기 이력, 도감 수집 현황, 토큰 소비량을 영구 추적할 수 없음.

## 2. 의사결정 (Decision)
- **클라이언트 UUID 기반 무마찰(Frictionless) 게스트 인증**:
  - 첫 접속 시 브라우저 `localStorage`에 UUID를 발급 및 보관.
  - `/api/v1/users/auth` 호출 시 해당 UUID와 매핑되는 유저 DB 레코드를 자동 생성/동기화.
- **20시간 토큰 쿨다운 리필 모델**:
  - LLM 심층 해석용 토큰은 최대 3개까지 보유 가능하며, 소모 시 20시간 주기로 1개씩 자동 충전.
  - PWA 앱 설치 시 +1 보너스 토큰 보상 제공.
  - 매일 연속 접속 시 '🔥 N일 연속 접속' 스트릭 뱃지 표시.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 0초 로그인 무마찰 진입 + 브라우저를 껐다 켜도 수집 데이터 및 토큰 영구 유지.
  - 20시간 쿨다운과 스트릭을 통한 일일 재방문(Retention) 유도.

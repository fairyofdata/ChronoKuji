# ADR-003: 3단계 스마트 오디오 엔진 (Local MP3 ➔ YouTube IFrame ➔ Web Audio Synth)

- **상태 (Status)**: `Accepted`
- **결정 일자 (Date)**: 2026-09-01
- **의사결정자**: 프론트엔드/오디오 아키텍트

---

## 1. 배경 및 문제 상황 (Context)
- 상용 OST(한스 짐머, 디즈니, 포켓몬, 넥슨 등) 원본 MP3 파일을 공개 GitHub 저장소 및 배포 서버에 직접 호스팅하면 **저작권 침해(DMCA Takedown)** 및 Git 용량 비대화 발생.
- 반면 음원을 전면 제외하면 일반 방문자가 무음 상태로 서비스를 이용하게 되어 시청각적 몰입감이 심각하게 훼손됨.

## 2. 의사결정 (Decision)
- **3단계 하이브리드 스트리밍 파이프라인 구축**:
  1. **1순위 (로컬 MP3)**: 사용자가 로컬에 MP3를 넣었으면 파일 기반 즉각 초고속 재생.
  2. **2순위 (YouTube IFrame 백그라운드 스트리밍)**: 로컬 파일이 없으면, `constants.js`에 사전 매핑된 YouTube 공식 OST ID를 통해 0px 숨김 IFrame 플레이어로 원곡 실시간 자동 스트리밍.
  3. **3순위 (Web Audio Synth)**: 오프라인(PWA) 상태이거나 네트워크 에러 시 브라우저 내장 Web Audio API가 핑크 노이즈 환경음을 합성하여 무음 방지.
- **오디오 싱글톤 (`globalAudio`)**: 비동기 오디오 객체 중복 재생 버그를 방지하기 위해 단일 플레이어 인스턴스 패턴 적용.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 공개 저장소 저작권 위반 위험 0%, Git 배포 용량 0바이트 달성.
  - 전 세계 모든 배포 사이트 접속자가 12개 세계관 전곡을 고음질로 즉시 감상 가능.

# ADR-002: 60초 타임록 및 지연 평가(Lazy Evaluation) 기반 차원 워프 시스템

- **상태 (Status)**: `Accepted`
- **결정 일자 (Date)**: 2026-08-31
- **의사결정자**: 시스템 아키텍트

---

## 1. 배경 및 문제 상황 (Context)
- 단순 클릭 한 번으로 모든 세계관을 즉시 전환할 수 있으면 '차원 여행'이라는 핵심 내러티브의 몰입감과 뽑기 1회의 소중함이 희석됨.
- 반면 서버에서 백그라운드 스케줄러(Celery/APScheduler)를 돌려 초 단위로 상태를 갱신하는 것은 과도한 서버 리소스 소모 유발.

## 2. 의사결정 (Decision)
- **60초(1분) 시공간 타임록 도입**:
  - 이동 시작 시 서버 DB에 `target_spot_id`와 `arrival_time = now() + 60초`를 기록.
  - 신규 유저는 5초 튜토리얼 초고속 워프 혜택 제공.
- **지연 평가(Lazy Evaluation) 패턴 채택**:
  - 서버 데몬 없이, 유저가 `/api/v1/users/me`를 조회하거나 `/api/v1/movement/arrive`를 호출하는 시점에 `now() >= arrival_time`을 검증하여 도착 확정.

## 3. 결과 및 영향 (Consequences)
- **장점**:
  - 서버 백그라운드 워커 없이 100% 무상태(Stateless) 고효율 서버 운영 가능.
  - 유저에게 '차원을 넘어가는 60초 동안의 BGM 감상 및 기대감'이라는 독보적인 감성 UX 부여.

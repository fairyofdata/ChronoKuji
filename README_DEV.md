## 📜 4. 정통 오미쿠지 7대 등급 & 차원 기록보관소

1. **7대 정통 등급 체계**:
   - `[ 大吉(대길) | 中吉(중길) | 小吉(소길) | 吉(길) | 末吉(말길) | 凶(흉) | 大凶(대흉) ]`
   - 12개 스팟 × 7개 등급 = **총 84건 정통 마스터 데이터 시딩 완료**
2. **미니멀 5대 세부운 & 운세 시(詩)**:
   - 소원, 인연, 재물, 사업, 이동, 기다림 6개 항목 + 운세 시구 + 행운 방위/숫자 + 점괘 묶기(結び)
3. **차원 점괘 기록보관소 (`HistoryModal.jsx`)**:
   - `GET /api/v1/omikuji/history` API 연동으로 과거의 모든 점괘와 유저의 고민, AI 심층 해석을 타임라인 카드로 열람.
4. **차원 이동 시 점괘 초기화**: 워프 시작 시 기존 점괘 뷰가 즉시 초기화되어 새로운 스팟 대기 카드로 전환.
